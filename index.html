Sync and backup

Sync works on the same Wi-Fi only. Your list goes straight from one device to the other and never touches a server.

  1. Copy this code to your other device (send it to yourself in a chat app).
  2. On the other device, choose "Join from the other device" and paste it.
  3. Paste the reply code it gives you below.
  1. Paste the code from your other device.
  2. Copy the reply code and paste it back on that device.
